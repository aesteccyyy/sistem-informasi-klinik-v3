# Catatan Sumber dan Lisensi

Repository ini dikembangkan dari source project Sistem Informasi Klinik v3 yang sebelumnya dipublikasikan di:

https://github.com/mulky-sulaiman/sistem-informasi-klinik-v3

README source tersebut menyebutkan "MIT - For testing purpose only". Karena keterangan itu membatasi tujuan penggunaan dan bukan salinan teks lisensi MIT standar, jangan menganggapnya sebagai izin penggunaan komersial. Pastikan izin tertulis dari pemegang hak sebelum mendistribusikan atau menggunakan turunan ini di luar tujuan yang diizinkan.

Perubahan lokal tidak menghapus kepemilikan atau lisensi komponen asal. Dependency seperti Laravel, Filament, dan paket Composer/NPM lainnya tunduk pada lisensi masing-masing; tinjau file lisensi paket sebelum mendistribusikan aplikasi.
